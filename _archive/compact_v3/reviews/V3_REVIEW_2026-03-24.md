## Critical Findings (must fix)

### 1. Plan Mode: Blocklist instead of Allowlist
**Lines**: 4383, 5188
**Issue**: `PLAN_MODE_BLOCKED_TOOLS` is a blocklist. New tools (e.g., `create_notebook`, MCP tools) bypass it automatically.
**Fix**: Invert to allowlist — only `PLAN_MODE_ALLOWED_TOOLS` can execute, everything else blocked.
**Status**: [x] FIXED 2026-03-24

### 2. bash Workspace Path Sandboxing
**Lines**: 1156, 2947, 3020
**Issue**: `bash` validates command patterns but not argument paths. `cat /etc/passwd` works.
**Fix**: Add workspace boundary check on file-path arguments in bash commands.
**Status**: [x] FIXED 2026-03-24

### 3. Thread Lock Leak
**Lines**: 6258, 6871, 6943, 6950
**Issue**: `ui_state["lock"]=True` set in wrapper, but early returns in `on_send`/`on_compact` skip unlock. Causes permanent "agent running" state.
**Fix**: Wrap entire threaded handler in `try/finally` that always releases lock.
**Status**: [x] FIXED 2026-03-24

### 4. Word Image Path Corruption (ROOT CAUSE of "charts missing")
**Line**: 3214
**Issue**: `img_path.lstrip("./")` on absolute paths like `/Users/foo/chart.png` strips the leading `/`, making it `Users/foo/chart.png` — which doesn't exist.
**Fix**: Only strip `./` prefix, don't use `lstrip` (which strips individual chars).
**Status**: [x] FIXED 2026-03-24

### 5. bash_allow_interpreters Default
**Line**: 681
**Issue**: `bash_allow_interpreters=True` by default allows `python` via `bash`, bypassing `python_exec` sandbox.
**Fix**: Default to `False`.
**Status**: [x] FIXED 2026-03-24

## High Findings

### 6. Python Sandbox `_original_import` Exposure
**Lines**: 3076, 3121, 3139
**Issue**: The original `__import__` is accessible in executed code, allowing bypass of import restrictions.
**Fix**: Remove `_original_import` from exec namespace; use closure instead.
**Status**: [x] FIXED 2026-03-24

### 7. Compaction Over-Aggressive
**Lines**: 6237, 6242, 6582, 6587
**Issue**: Pre-send and post-send always jump to LLM summarize at 80/90%. Prune alone may be sufficient.
**Fix**: Try prune first, only summarize if still above threshold after pruning.
**Status**: [x] FIXED 2026-03-24

### 8. File Dedup Not Cleared After Compaction
**Lines**: 608, 2411, 6899
**Issue**: Files marked "already in context" survive compaction. Agent can't re-read files it needs.
**Fix**: Clear `FILE_CACHE._in_context` after compaction.
**Status**: [x] FIXED 2026-03-24

### 9. Summary Prompt Inconsistency
**Lines**: 283, 299, 308
**Issue**: Prompt says "ALL user messages verbatim" but input truncated to ~20 messages.
**Fix**: Change prompt to "user messages from the included context" or increase limit.
**Status**: [x] FIXED 2026-03-24

### 10. PDF Silently Drops Missing Images
**Line**: 3947
**Issue**: If image doesn't exist, PDF just skips it with no placeholder or error.
**Fix**: Add `[Image not found: path]` placeholder paragraph.
**Status**: [x] FIXED 2026-03-24

### Security Assessment (High-Security SageMaker)

V3 is designed for SageMaker notebooks in enterprise AWS accounts. Security layers:

1. **AWS IAM**: SageMaker execution role controls all AWS access
2. **Bedrock model access**: Only approved models via IAM policy
3. **Workspace boundary**: All file ops restricted to workspace dir
4. **Bash allowlist**: Only approved commands, no interpreters by default
5. **Python sandbox**: Closure-based import hook, module allowlist
6. **Path sandboxing**: Layer 4 blocks absolute paths outside workspace
7. **SSRF protection**: Network commands blocked by default
8. **Secret detection**: 13 patterns scanned on output
9. **Audit logging**: All tool calls logged with args and results
10. **Approval dialogs**: Dangerous tools require explicit user approval
11. **Exec limits**: 40 calls / 900 seconds per session
12. **Symlink protection**: `os.path.realpath` + `validate_path` on all file ops
