Future Software Development Lessons From compact_v5

Date: 2026-05-11

Source: compact_v5 build history, reference comparisons, changelogs, implementation/status files, tests, results, reviews, notes_cli acceptance, and S3 real-use transcript.

Do not only test whether the machinery works. Test whether the user can see, trust, and steer the machinery while it works.

Core Lessons

LessonPlain-English meaningFuture use
Benchmark pass is not product readinessv3 passed, but S3 real-use still failed.Pair every benchmark with real transcript tests.
UI is supervisionThe notes_cli run felt stuck while work was happening.Show tools, tests, subagents, cost, blockers, and status live.
Tool truth must match executor truthS3 was documented as possible, but both attempted paths failed.Every tool promise needs an executable smoke test.
Drift is a product failureThe agent moved from S3 inventory to source-tree inventory.Fallbacks must stay anchored to original intent.
Cost is a behavior signal7 calls for one simple S3 request exposed retry and verbosity bugs.Treat cost spikes as bug reports with behavior attribution.
Review is infrastructureClaude review initially used the wrong auth route.Document and test the reviewer command, auth, prompt, output, and verdict.
Packaging is implementationSource fixes do not matter if the zip is stale.Rebuild and hash-verify shipped artifacts after relevant changes.
Lessons need synthesisThe repo had much evidence but needed a principle layer.Every serious incident gets a technical issue doc plus a learning note.
Notebook thinness is a product contractv5 copied parts of v4's UI ritual but let the notebook become a long integration script.Keep launch cells small; move path/config/display complexity into tested Python helpers and render-check the target widget runtime.
Callback plumbing needs end-to-end proofThe first ask_user UI patch looked right visually, but the engine did not pass the provider into tool dispatch.For every interactive callback, pair the screenshot with an engine/tool smoke test that proves the model can actually reach it.
