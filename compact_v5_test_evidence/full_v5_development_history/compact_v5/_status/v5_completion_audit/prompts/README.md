# Prompt Archive

Every prompt sent to a worker or Claude reviewer must be copied here before
execution. Codex prompts in this redo are worker prompts only, never reviewer
prompts.

Naming:

```text
YYYYMMDD-HHMM-block-a-codex-worker-iter1.txt
YYYYMMDD-HHMM-block-a-claude-reviewer-iter1.txt
YYYYMMDD-HHMM-block-a-codex-fix-iter2.txt
```

Each block's `PROMPTS.md` must link to the copied prompt files.
