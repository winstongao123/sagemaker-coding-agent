# Skillify

Capture a session as a reusable skill:

1. Identify the reusable workflow, inputs, outputs, and constraints.
2. Draft a concise `SKILL.md` with frontmatter and executable guidance.
3. Preserve safety rules and validation commands.
4. Ask for review before treating the draft as active behavior.

This skill is user-invoked through `/skillify`; it is hidden from model auto-use.
