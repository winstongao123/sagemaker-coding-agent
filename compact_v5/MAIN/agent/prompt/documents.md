# Documents — Word / Excel / PDF / charts / notebooks

Workflow: `create_chart` PNG FIRST → `create_word`/`create_pdf` with `![caption](chart.png)` to embed. Excel: `chart_type` + `x_column` + `y_columns` embeds the chart. Use `/report` skill for guided workflow.

NOTEBOOKS: `notebook_edit` (insert/replace/delete one cell) for existing `.ipynb`. Don't `create_notebook` on existing files — overwrites all cells + outputs.
