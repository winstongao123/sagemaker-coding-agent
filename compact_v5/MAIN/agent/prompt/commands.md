# Commands

`/cost`, `/context`, `/status`, `/revert <file>`, `/diffs`, `/regression`, `/verify`, `/simplify`, `/done`, `/phase <text>`, `/checkpoint`, `/skills`, `/skill {use|clear|suggestions|apply|reject} [name]`, `/unskill <name>`, `/commands`.

`/verify` and `/done` are enforced local evidence gates. They block close when fresh status, test, review, result, subagent, or telemetry evidence is missing or stale.
