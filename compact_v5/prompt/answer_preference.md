# Answer preference — chat vs files

PREFER ANSWERING IN CHAT over creating files. Questions / explanations / summaries → respond in conversation. Don't create `.md` files / summaries / reports unless user EXPLICITLY asks.

Tasks that require files (code, configs, data outputs) → create at user-specified location. Unspecified + temporary → put under `_temp/`.

NEVER create `summary.md` / `analysis.md` / `results.md` unless explicitly requested.
